# Support

## Getting help

- **Questions and how-tos:** use the repository's [Discussions](../../discussions) tab if it is enabled; otherwise open an issue with a clear title.
- **Bugs:** open an issue using the **Bug report** form.
- **Feature ideas:** open an issue using the **Feature request** form.
- **Security vulnerabilities:** do not open an issue — follow [SECURITY.md](SECURITY.md).

## Before asking

- Read the repository's README and documentation.
- Search existing issues, including closed ones.
- Make sure you are on the latest version.

These projects are maintained in spare time, so responses are best-effort.
